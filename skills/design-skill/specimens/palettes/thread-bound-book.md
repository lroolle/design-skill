# thread bound book -- bamboo paper, ink, red border rules

Provenance: a Qing-dynasty thread-bound volume (线装书), bamboo paper
yellowed to straw, black ink text, the border rules (边栏) and fish-tail
(鱼尾) printed in red on a 套印 edition. Set by eye against an original
under daylight and a scan.

## The irregularity

Straw paper (85) is the ground, with visible chroma; the ink is a
warm black (75), warmer than carbon on white because it soaked into
the fiber. The red rules are a cinnabar that has faded toward
orange-pink (35) and sit lighter than a fresh stamp; they are
*structure*, not accent -- the frame and column lines. So on this card
the accent hue owns the lines, and emphasis inside the text is done
by size and 着重号, not by color.

## Inks

```
straw        oklch(0.935 0.030 85)      --bg
straw toned  oklch(0.905 0.032 84)      --surface
straw deep   oklch(0.870 0.035 82)      --surface-2
ink          oklch(0.250 0.015 75)      --fg
ink thin     oklch(0.470 0.014 75)      --fg-2
ink faint    oklch(0.560 0.012 75)      --fg-3
red rule     oklch(0.760 0.090 35)      --line          (the column lines are red)
red border   oklch(0.620 0.130 35)      --line-strong
seal         oklch(0.560 0.180 30)      --accent        (the collector's seal, rare)
seal ghost   oklch(0.930 0.035 35)      --accent-soft
```

## Must not become

Cream + serif + terracotta -- the exact reflex this material is
nearest to. What keeps it away: the rules are red and structural
(nobody's terracotta accent is a grid), the text is set in Song at a
zh measure, and there is no italic anywhere.
