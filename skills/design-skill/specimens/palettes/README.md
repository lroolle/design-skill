# palette specimens

Observed palettes, not generated ones. Each card names the physical
artifact its inks were set against, gives the values, and -- the part a
seed-hue ramp cannot produce -- states the **irregularity**: which
material is a different hue from which, why the rule is not the ink
diluted, where the one chroma sits. Values were set by eye against
photographs and the objects themselves and are marked so; none came
from a formula.

Use: pick the card nearest the world or the subject; map its inks onto
the token names; re-check contrast (`--fg-3` on `--bg` must clear
4.5:1); write the provenance line into DESIGN.md. Changing a hue by
formula turns a specimen back into a ramp; if a card does not fit, take
a different card or observe a new artifact.

The seven system palettes live in their own contracts (`systems/*.css`)
and are not repeated here. Adding a card: photograph the object under
daylight, set the values by eye at 1x and 2x, write the irregularity
before the values, and name the reflex it must not become.
