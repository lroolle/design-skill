# type specimens

Real settings at real sizes, pasteable. Each file is one job (zh body,
Latin body, the data table, zh display) with the CSS that sets it and
the numbers that were tuned by eye against a rendered page, not
derived from a ratio. Start from the one nearest the surface; change
the face, keep the relationships.
