Events / create

Send an event

Create one immutable event and receive the address that consumers will acknowledge.

Fixture contract. The endpoint and payload below are sample data for this structural base.

Request

Send a client-generated idempotency key. Retrying the same key returns the first event instead of creating a second one.

curl -X POST /v3/events \
  -H "Idempotency-Key: evt-1048" \
  -d '{"topic":"release.ready"}'
HTTP/1.1 201 Created
{
  "id": "ev_1048",
  "state": "accepted"
}
