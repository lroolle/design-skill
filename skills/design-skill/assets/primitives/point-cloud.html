The size rule

A point cloud does not scale by scaling. Shrink it uniformly and it turns to grey mush: the dots fall under a pixel and the silhouette dissolves. Count falls faster than size, radius falls slower. Same parameters, three sizes, no per-size lookup table.

The floor

Under prefers-reduced-motion the loop never starts and the cloud holds its settled frame — same composition, same information, no motion. Not a blank, not a fallback spinner. It also parks itself off-screen and in a hidden tab.
